# Emberline

Infrastructure-independent last-mile wildfire warning, simulated end to end.

In the 2023 Lahaina fire the fire was detected and more than a hundred people
still died, because power, cell service and the sirens failed at the moment
they were needed. Every incumbent ends in an internet notification. Emberline
is a neighbourhood smoke alarm for the wildland-urban interface: solar mesh
sensor nodes on consented private property, an on-node smoke classifier, a
self-healing LoRa alert mesh with a three-tier escalation ladder (chirp →
voice with bearing → full cascade) that works with the grid, the towers and
the internet all down, and *Foresight*, a physics-trained neural fire
forecaster that draws probability cones, routes evacuation traffic around
them, and drafts a county alert for a human to approve. This repository is
the **software simulation of that whole chain**, tested and measured.

> **Honesty statement.** Everything in this repository is synthetic
> simulation. No physical node, radio, real sensor reading, real terrain or
> real fire record has been used. No metric here is evidence of real-world
> performance. The hardware, the field data, the county integration and the
> business model are PLANNED or NOT BUILT; the full list is in
> [docs/04_GAP_REGISTER.md](docs/04_GAP_REGISTER.md).

## Quickstart (fresh clone, CPU only, Python 3.11+)

```bash
python -m pip install -e .

# the whole MVP in one command: verify (lint + 61 tests + smoke),
# canonical demo, pitch assets, and a dated summary in docs/MVP_RUN.md
make mvp                      # or: python -m emberline.mvp

# pieces
bash verify.sh                # lint + tests + fast end-to-end smoke (~2.5 min)
python -m emberline.demo --scenario ridgeline --fast --kill-node N3 --wind-shift 40
python -m emberline.demo --scenario ridgeline          # narrated, ~3 minutes
```

Trained checkpoints are committed, so the demo and tests run from a fresh
clone. Regenerating the training data and the REPORT metrics from scratch:

```bash
python -m emberline.surrogate.data && python -m emberline.surrogate.train
python -m emberline.surrogate.eval          # -> metrics/surrogate.json, REPORT.md
python -m emberline.surrogate.calibration   # -> metrics/calibration.json
python -m emberline.detect.data && python -m emberline.detect.train
python -m emberline.detect.eval             # -> metrics/detect.json, REPORT.md
python -m emberline.foresight.hindcast scenarios/*.yaml
python -m emberline.demo.pitch_assets       # six 1920x1080 PNGs from run artifacts
```

If `make` is not installed (some Windows setups), `python -m emberline.mvp`
runs the same steps and falls back to `bash verify.sh`.

## Headline measured numbers (synthetic)

| metric | value |
|---|---|
| Surrogate burned-area IoU @ +30 min, unseen worlds / held-out wind regime | 0.627 / 0.657 (target 0.80 missed) |
| Surrogate ensemble calibration, ECE (raw, shipped) | 0.060 |
| Surrogate ensemble speedup vs this repo's fast physics | 0.5× (target 100× missed; baseline is a toy CA) |
| Smoke detection F1 on held-out events, 1D-CNN / GBM | 0.943 / 0.952 (CNN did not beat the baseline) |
| False positives per node-day on a confounder-rich ambient day (CNN) | 7.33 |
| Detection latency from plume arrival, median | 36 s |
| Canonical demo: ignition → Tier-0 / Tier-1 / Tier-2 cascade | 30 s / 120 s / 300 s |
| Hindcast warning minutes gained vs authored 911 call, 6 scenarios | +19.5, +7.5, −6.5, three misses |
| Test suite | 61 tests (54 original + 7 for the MVP entrypoint), passing |

## Repository layout

```
emberline/
  config.py        one config.yaml, one seed, deterministic RNG streams
  worldgen/        fractal terrain, clustered fuel, town + road graph, OU-gust wind
  firesim/         Rothermel-inspired CA spread + Monte Carlo ensembles
  surrogate/       dataset gen, 371,858-param UNet, training, eval, calibration
  sensors/         Gaussian plume, diurnal baselines, six authored confounders
  detect/          60-s window smoke classifier (1D-CNN vs GBM baseline)
  mesh/            discrete-event LoRa-class mesh + Tier 0/1/2 escalation ladder
  foresight/       triangulation, probability cones, evacuation routing, CAP drafts, hindcast
  demo/            scripted end-to-end demo CLI, frame renderer, pitch assets
  adapters/        STUBS for real data (USGS 3DEP, LANDFIRE, OSM): interfaces only
  mvp.py           one-command MVP run -> docs/MVP_RUN.md
  report.py        metrics JSON store + REPORT.md section writer
tests/             61 pytest tests (54 original + 7 in test_mvp.py)
scenarios/         6 hand-authored hindcast scenarios (not fire records)
metrics/           JSON produced by the eval CLIs; read by the demo scoreboard
data/checkpoints/  committed surrogate + detector checkpoints
demo/out/          generated frames/GIF (ignored) + committed pitch PNGs
docs/              this documentation set
config.yaml        every parameter
verify.sh          lint + tests + smoke; Makefile targets: verify, test, demo, mvp
```
